# Web-Based 3D Printing Service Ordering Management System for TechWorkz

## Overview
This capstone project was developed for TechWorkz 3D Printing Services to streamline customer order processing, automate pricing calculations, improve communication, and centralize record management.

## Features
- User Registration and Login
- Guest Browsing
- Ready-to-Print Model Catalog
- Custom 3D Model Upload
- Automated Cost Calculator
- Order Tracking
- Real-Time Messaging/Chat
- Payment Monitoring and Verification
- Reports Generation

## Technologies Used
- WordPress CMS
- PHP
- MySQL
- JavaScript
- HTML
- CSS
- Apache Web Server
